# Live Fruit Juice — স্টাফ বিলিং অ্যাপ

দোকান কাউন্টারে ফোন/ট্যাবলেটে ব্যবহারের জন্য একটি দ্রুত POS বিলিং ওয়েব অ্যাপ।
বাংলা ইন্টারফেস, 58mm রিসিট প্রিন্ট, Supabase ব্যাকএন্ড, কাস্টম লগইন (Supabase Auth ছাড়া)।

---

## ফিচার

| ফিচার | বিবরণ |
|---|---|
| লগইন | SHA256 (`livefruitjuice_salt_` + পাসওয়ার্ড) — Supabase Auth ব্যবহার করে না |
| রোল | `staff` → শুধু নিজের বিল; `owner` → সব স্টাফের বিল + সেটিংস |
| বিলিং | প্রোডাক্ট + S/M/L সাইজ বাটন, সার্চ, কার্ট, লাইভ টোটাল |
| ফেরত/বাকি | লাইভ হিসাব — ফেরত সবুজ, বাকি লাল |
| রিসিট | 58mm ন্যারো ফরম্যাট, `window.print()`, অটো প্রিন্ট |
| আজকের বিলসমূহ | তারিখ + সেলার ফিল্টার, রিপ্রিন্ট বাটন |
| Realtime | `products` টেবিলে পরিবর্তন হলে সাথে সাথে আপডেট (রিফ্রেশ ছাড়াই) |
| সেটিংস | দোকানের নাম, মোবাইল, ঠিকানা (শুধু ওনার) |
| PWA | মোবাইলে "Add to Home Screen" করা যায় |
| শর্টকাট | `F2` সার্চ, `F4` বিল কমপ্লিট |

## সেটআপ (৩ ধাপ)

### ধাপ ১ — Supabase এ ডেটাবেস তৈরি

Supabase Dashboard → **SQL Editor** → **New query** → `supabase-setup.sql` ফাইলের
পুরো কনটেন্ট কপি করে **Run** করুন।

এটি একবার চালালেই হবে। এতে তৈরি হবে:
- টেবিল: `employees`, `products`, `invoices`, `invoice_items`
- নিরাপদ লগইন ফাংশন: `login_employee(username, hash)`
- RLS পলিসি
- Realtime (products)
- ডিফল্ট ওনার: **`owner` / `owner123`**
- কিছু স্যাম্পল প্রোডাক্ট (না চাইলে মুছে দিন)

### ধাপ ২ — Vercel-এ ডিপ্লয়

এই ফোল্ডারটি টার্মিনালে ওপেন করে:

```bash
npm i -g vercel
vercel login
vercel --prod
```

প্রথমবার জিজ্ঞেস করবে — হ্যাঁ (Yes) দিন। শেষে একটা লিংক দেবে, যেমন
`https://live-fruit-juice.vercel.app`।

### ধাপ ৩ — অ্যাপে Supabase তথ্য দিন

লিংকে যান — **একটা সেটআপ স্ক্রিন আসবে**। সেখানে বসান:

- **Project URL** — Supabase → Project Settings → API
- **anon public key** — একই পেজ থেকে

সেভ করলেই অ্যাপ চালু। তথ্য ফোনের মধ্যেই সেভ থাকে, পরে আর ডিপ্লয় লাগবে না।

<details>
<summary><b>বিকল্প: config.js-এ সরাসরি বসাতে চাইলে</b></summary>

`config.js` ফাইলে URL ও key বসিয়ে আবার `vercel --prod` চালান।
তাহলে সেটআপ স্ক্রিন আর দেখাবে না — সব ডিভাইসে কাজ করবে।
</details>

## স্টাফ অ্যাকাউন্ট বানানো

অ্যাপে কোনো স্টাফ-ম্যানেজমেন্ট স্ক্রিন নেই (ডেস্কটপ অ্যাপের কাজ)।
নতুন স্টাফ যোগ করতে SQL Editor-এ:

```sql
insert into employees (username, password_hash, role)
values (
  'rakib',
  encode(digest('livefruitjuice_salt_1234', 'sha256'), 'hex'),
  'staff'
);
```

- `password_hash` = `SHA256('livefruitjuice_salt_' || পাসওয়ার্ড)`
- `role` = `'staff'` অথবা `'owner'`

## নিরাপত্তা

- `password_hash` কখনো ব্রাউজারে আসে না — লগইন `login_employee` RPC
  ফাংশনের মধ্যে সার্ভার সাইডে তুলনা হয়।
- `employees` টেবিলে RLS চালু, সরাসরি পড়া বন্ধ।
- অ্যাপে কোনো signup / forgot-password নেই।

## ট্রাবলশুটিং

**সেটআপ স্ক্রিন আসছে, লগইন করতে পারছি না**
→ অ্যাপে Supabase তথ্য এখনো দেওয়া হয়নি। লিংকে গিয়ে URL ও anon key দিন।

**সেটআপ স্ক্রিনের পরও সেটআপ স্ক্রিন আসছে**
→ ব্রাউজারে localStorage ক্লিয়ার করুন, অথবা সেটিংস থেকে "আবার শুরু করুন" চাপুন।

**"সাপ্লাবেস কনফিগারেশন পাওয়া যায়নি"**
→ `config.js`-এ URL ও Key নেই, অথবা ফাইলটি আপলোড করা হয়নি।

**লগইন করলেই লগআউট হয়ে যাচ্ছে / কোনো এরর নেই**
→ Supabase → Authentication → **Authentication** চালু আছে কিনা দেখুন।
→ SQL Editor-এ `login_employee` ফাংশন তৈরি হয়েছে কিনা দেখুন।

**পণ্য আপডেট হচ্ছে না (Realtime)**
→ `supabase-setup.sql`-এর ধাপ ২ চালান, অথবা Database → Replication →
   `supabase_realtime` পাব্লিকেশনে `products` টেবিলটি যোগ করুন।

**নতুন স্টাফ লগইন করতে পারছে না**
→ `password_hash` কমান দিয়ে তৈরি হতে হবে:
   `encode(digest('livefruitjuice_salt_পাসওয়ার্ড','sha256'),'hex')`

**প্রিন্টে পেজের বাকি অংশও আসছে**
→ ব্রাউজারের প্রিন্ট ডায়ালগে "Paper size" 58mm বা "Custom" সিলেক্ট করুন।
