# Live Fruit Juice — স্টাফ বিলিং সিস্টেম

দোকান কাউন্টারে ফোন/ট্যাবলেটে ব্যবহারের জন্য একটি সম্পূর্ণ POS বিলিং অ্যাপ।
বাংলা ইন্টারফেস, 58mm রিসিট প্রিন্ট।

**ডেটা এখন Vercel-এর সার্ভারে (Vercel KV) সেভ হয়** — সব ফোন, ট্যাবলেট ও
ব্রাউজারে একই ডেটা দেখা যাবে। কোনো npm প্যাকেজ লাগে না, কোনো build command লাগে না।

## ফিচার

| ফিচার | বিবরণ |
|---|---|
| **সার্ভার ডেটা** | Vercel KV (Upstash Redis) — সব ডিভাইসে একই বিল, পণ্য, স্টাফ |
| **সার্ভারে লগইন** | পাসওয়ার্ড scrypt দিয়ে হ্যাশ, httpOnly কুকি সেশন, ব্রুট-ফোর্স থ্রটল |
| **স্টাফ রোল** | সার্ভারেই সীমিত — শুধু নিজের বিল দেখতে ও প্রিন্ট করে |
| **ওনার রোল** | সব স্টাফের বিল + স্টাফ ফিল্টার + সম্পূর্ণ নিয়ন্ত্রণ |
| **ইন্টারনেট ছাড়াই বিক্রি** | নেটওয়ার্ক না থাকলে বিল কিউ করে রাখা হয়, ইন্টারনেট ফিরেই সার্ভারে চলে যায় |
| **পণ্য ম্যানেজ** | ওনার অ্যাপ থেকেই পণ্য যোগ/এডিট/ডিলিট ও S/M/L দাম |
| **স্টাফ ম্যানেজ** | ওনার অ্যাপ থেকেই স্টাফ যোগ/এডিট/ডিলিট |
| **সেটিংস** | দোকানের নাম, ঠিকানা, মোবাইল — রিসিটে দেখায় |
| বিলিং | প্রোডাক্ট + সাইজ বাটন, সার্চ, কার্ট, লাইভ টোটাল |
| ফেরত/বাকি | লাইভ হিসাব — ফেরত সবুজ, বাকি লাল |
| রিসিট | 58mm ন্যারো ফরম্যাট, `window.print()`, অটো প্রিন্ট, রিপ্রিন্ট |
| ব্যাকআপ | এক ক্লিকে পুরো ডেটা JSON ফাইলে ডাউনলোড, ফিরিয়েও আনা যায় |
| PWA | মোবাইলে "Add to Home Screen" করা যায় |
| শর্টকাট | `F2` সার্চ, `F4` বিল কমপ্লিট |

## Vercel-এ ডিপ্লয় (৩ ধাপ)

### ধাপ ১: KV ডেটাবেস বানান

১. [vercel.com](https://vercel.com)-এ লগইন করুন
২. প্রজেক্ট খোলার পর **Storage** ট্যাবে যান
৩. **Create Database** → **Vercel KV** সিলেক্ট করুন → নাম দিন → **Create**

> Vercel-এর নিজস্ব ফ্রি প্ল্যানে KV চালু করা যায়, আলাদা কার্ড লাগে না।

### ধাপ ২: Environment Variables

প্রজেক্টের **Settings → Environment Variables**-এ গিয়ে দুটি ভ্যারিয়েবল যোগ করুন:

| Key | Value |
|---|---|
| `KV_REST_API_URL` | যেটা ধাপ ১-এ পেয়েছেন (যেমন `https://xxxx.upstash.io`) |
| `KV_REST_API_TOKEN` | KV টোকেন (লম্বা লেবেল) |

**তিনটি environment-এই যোগ করুন** — Production, Preview, Development — তাহলে
প্রতিটা ডিপ্লয়ে কাজ করবে।

### ধাপ ৩: ডিপ্লয়

এই ফোল্ডারটি GitHub-এ পুশ করুন, তারপর
**Add New → Project** → রিপোজিটরি সিলেক্ট → **Deploy**।

কোনো build command বা অন্য environment variable লাগবে না।
Vercel `api/` ফোল্ডারের ফাইলগুলো স্বয়ংক্রিয়ভাবে serverless function বানিয়ে দেবে।

## ডেটা কোথায় থাকে

সব ডেটা **Vercel KV**-তে, এভাবে:

```
lfj:settings               দোকানের সেটিংস
lfj:products               পণ্যের তালিকা ও দাম
lfj:staff                  স্টাফ (পাসওয়ার্ড scrypt হ্যাশ সহ)
lfj:inv:20260926-001       একটি বিল + তার আইটেম
lfj:idx:2026-09-26         দিনের বিল নম্বরগুলোর তালিকা
lfj:seq:20260926           দিনের বিল নম্বর কাউন্টার (atomic — কখনো ডুপ্লিকেট হয় না)
lfj:sess:<hash>            লগইন সেশন (30 দিন, শুধু টোকেনের হ্যাশ)
lfj:try:<user>:<ip>        ভুল লগইন চেষ্টার গণনা
```

**প্রতিটি বিল আলাদা key**, তাই দুইজন স্টাফ একসাথে বিক্রি করলেও কোনো বিল
হারায় না — যা একটি বড় JSON ব্লবে হতো।

**ক্লায়েন্টে (ব্রাউজারে)** রাখা হয় শুধু: দ্রুত দেখানোর ক্যাশ, আর ইন্টারনেট ছাড়া
নেওয়া বিলের সারি (queue)। ব্রাউজারের ডেটা মুছে গেলেও সার্ভারের ডেটা নিরাপদ।

## ইন্টারনেট ছাড়া কী হয়

| পরিস্থিতি | অ্যাপ কী করে |
|---|---|
| ইন্টারনেট আছে | বিল সরাসরি সার্ভারে যায়, হেডারে "সেভ হয়েছে" দেখায় |
| ইন্টারনেট নেই | বিলটি ফোনেই সেভ হয় (`TEMP-001` নম্বরে), হেডারে "অফলাইন" দেখায়, রিসিট প্রিন্ট হয় |
| ইন্টারনেট ফিরলে | বাকি বিলগুলো নিজে থেকেই সার্ভারে যায়, আসল বিল নম্বর বসে যায় |
| অন্য ডিভাইসে খুললে | সব বিল আগের দিন থেকেই দেখা যায় |

**বিল নম্বর দ্বিতীয়বার হয় না** — প্রতিটি বিলের একটি `client_id` থাকে, তাই
ইন্টারনেট নড়াচড়ার কারণে একই বিক্রি দুইবার জমা হতে পারে না।

## প্রথমবার ব্যবহার

**লগইন:** `owner` / `owner123`

1. **স্টাফ ম্যানেজ** → মালিকের পাসওয়ার্ড বদলান
2. **সেটিংস** → দোকানের নাম, ঠিকানা, মোবাইল দিন
3. **পণ্য ম্যানেজ** → নিজের পণ্যের দাম দিন (স্যাম্পল পণ্য মুছে দিন)
4. স্টাফদের অ্যাকাউন্ট বানান — তারা শুধু নিজের বিল দেখতে পাবে

### আগের (localStorage) ডেটা সার্ভারে আনা

আগের সংস্করণে ব্রাউজারে সেভ থাকা বিল থাকলে, প্রথমবার লগইন করার পর মালিককে
অ্যাপ নিজে জিজ্ঞেস করবে সেগুলো সার্ভারে নিতে চান কি না।

## ব্যাকআপ ও রিস্টোর

- **ব্যাকআপ নিন**: সেটিংস → "ব্যাকআপ ফাইল নিন" → `livefruitjuice-backup-YYYY-MM-DD.json`
- **ফেরান**: সেটিংস → "ফাইল থেকে ডেটা নিন" → ফাইল বেছে নিন

ফাইল ইমপোর্ট করার আগে সার্ভার ফাইলটি যাচাই করে (dry-run) — ভুল ফাইল দিলে
কিছু মুছে যায় না। ইমপোর্টে **বিল, পণ্য ও সেটিংস** বদলায়; **স্টাফ অ্যাকাউন্ট ও
পাসওয়ার্ড অপরিবর্তিত থাকে**, তাই ভুল ফাইলে নিজের লগইন হারানোর ভয় নেই।

## নিরাপত্তা

| বিষয় | কী করা হয়েছে |
|---|---|
| পাসওয়ার্ড | scrypt (N=16384) + প্রতি ইউজারে আলাদা সল্ট; সার্ভারেই হ্যাশ হয় |
| সেশন | ৩২ বাইট র‍্যান্ডম টোকেন, httpOnly + SameSite কুকিতে; ডেটাবেজে শুধু টোকেনের SHA-256 |
| রোল চেক | সার্ভারে — স্টাফ সরাসরি API চালালেও অন্যের বিল/পণ্য দেখতে পারে না |
| দাম | সার্ভার ক্যাটালগের দামই ধরে, ক্লায়েন্ট পাঠানো দাম উপেক্ষিত হয় |
| ভুল লগইন | ১৫ মিনিটে ৮ বারের বেশি চেষ্টা বন্ধ |
| নিষ্ক্রিয় স্টাফ | লগইন ও চলমান সেশন সাথে সাথে বন্ধ হয় |
| ব্রাউজার ক্যাশ | রিস্পন্সে `Cache-Control: no-store` |

## ট্রাবলশুটিং

**"ডেটাবেস কনফিগার করা নেই" দেখাচ্ছে**
→ `KV_REST_API_URL` ও `KV_REST_API_TOKEN` সেট করা নেই বা ভুল প্রজেক্টে দেওয়া হয়েছে।
প্রজেক্টের Storage ট্যাবে KV আছে কি না দেখুন, তারপর Deploy আবার চালান।

**লগইনে "সার্ভারের সাথে সংযোগ হচ্ছে না"**
→ `/api` ফাংশন ডিপ্লয় হয়েছে কি না দেখুন: `আপনার-সাইট.vercel.app/api/auth` খুললে
JSON দেখানো উচিত। যদি 404 আসে, ফোল্ডারে `api/` ডিরেক্টরি আছে কি না দেখুন।

**অফলাইন বিল পাঠানো হচ্ছে না**
→ হেডারে "Nটি বিল বাকি" দেখলে ব্যানারের **"এখনই পাঠান"** বাটনে চাপুন, অথবা
ইন্টারনেট ফিরলে নিজে থেকেই যাবে।

**স্টাফ নিজের বিল দেখতে পাচ্ছে না**
→ `api/staff.js` ছোট ফাইলে ভুল ঢোকা পড়লে পুরো অ্যাপ লোড হবে না। ডিপ্লয় লগে
কোনো এরর আছে কি না দেখুন।

**প্রিন্টে পেজের বাকি অংশও আসছে**
→ ব্রাউজারের প্রিন্ট ডায়ালগে "Paper size" 58mm বা "Custom" সিলেক্ট করুন।

**ভুল ফাইল ইমপোর্ট করলে ডেটা মুছে গেছে**
→ ফাইলটি আগে যাচাই হয় (dry-run)। ব্যাকআপ ফাইল থাকলে সেটা আবার ইমপোর্ট করুন।
