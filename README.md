# Live Fruit Juice — স্টাফ বিলিং সিস্টেম

দোকান কাউন্টারে ফোন/ট্যাবলেটে ব্যবহারের জন্য একটি সম্পূর্ণ POS বিলিং অ্যাপ।
বাংলা ইন্টারফেস, 58mm রিসিট প্রিন্ট, **সব ডেটা একটি JSON ফাইলে** — কোনো বাহ্যিক
সার্ভিস (Supabase ইত্যাদি) লাগে না।

---

## ফিচার

| ফিচার | বিবরণ |
|---|---|
| লগইন | SHA256 (`livefruitjuice_salt_` + পাসওয়ার্ড), কাস্টম টোকেন |
| **স্টাফ রোল** | শুধু নিজের বিল দেখে ও প্রিন্ট করে |
| **ওনার রোল** | সব স্টাফের বিল + স্টাফ ফিল্টার + সম্পূর্ণ নিয়ন্ত্রণ |
| **পণ্য ম্যানেজ** | ওনার অ্যাপ থেকেই পণ্য যোগ/এডিট/ডিলিট ও S/M/L দাম |
| **স্টাফ ম্যানেজ** | ওনার অ্যাপ থেকেই স্টাফ যোগ/এডিট/ডিলিট |
| **সেটিংস** | দোকানের নাম, ঠিকানা, মোবাইল — সব ডিভাইসে একই |
| বিলিং | প্রোডাক্ট + সাইজ বাটন, সার্চ, কার্ট, লাইভ টোটাল |
| ফেরত/বাকি | লাইভ হিসাব — ফেরত সবুজ, বাকি লাল |
| রিসিট | 58mm ন্যারো ফরম্যাট, `window.print()`, অটো প্রিন্ট, রিপ্রিন্ট |
| **লাইভ আপডেট** | SSE — পণ্য বদলালে সব ডিভাইসে সাথে সাথে দেখায় |
| ব্যাকআপ | এক ক্লিকে পুরো ডেটা JSON ফাইলে ডাউনলোড, ফিরিয়েও আনা যায় |
| PWA | মোবাইলে "Add to Home Screen" করা যায় |
| শর্টকাট | `F2` সার্চ, `F4` বিল কমপ্লিট |

## দ্রুত শুরু (লোকাল)

```bash
npm install
npm start
```

ব্রাউজারে **http://localhost:3000** খুলুন।

**প্রথম লগইন:** `owner` / `owner123`

> ⚠️ লাইভে নেওয়ার আগে সেটিংস গিয়ে পাসওয়ার্ড বদলে নিন।

## ফাইল কাঠামো

```
server.js             সার্ভার + API (Node/Express, একটি ফাইলেই ডেটা)
data/db.json          ← সব ডেটা এখানে (স্বয়ংক্রিয়ভাবে তৈরি হয়)
public/
  index.html          সব পেজ
  css/style.css       স্টাইল, ডার্ক মোড, রেসপন্সিভ, 58mm প্রিন্ট স্টাইল
  js/app.js           সব ফ্রন্টএন্ড লজিক
  manifest.json       PWA
```

`data/db.json` ফাইলটিই একমাত্র ডেটাবেজ — কপি করে রাখলেই ব্যাকআপ হয়ে যাবে।

## ডিপ্লয়

### ⚠️ Vercel-এ চলবে না

Vercel-এর সার্ভারলেস ফাইলসিস্টেম **read-only** — কোনো ফাইল লেখা যায় না
(`/tmp` মুছে যায়)। তাই বিলের ডেটা সেখানে টিকবে না।

যেসব হোস্টে **persistant disk** আছে, সেখানে কাজ করবে:

| হোস্ট | নোট |
|---|---|
| **Railway** | সহজ — নিচের ধাপে দেখুন |
| **Render** | free tier-এ disk মুছে যায়, paid দরকার |
| **আপনার VPS / cPanel** | Node চালানোর সুবিধা থাকলে সবচেয়ে ভালো |

### Railway-এ ডিপ্লয় (সবচেয়ে সহজ)

1. কোডটি GitHub-এ পুশ করুন
2. [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub**
3. রিপোজিটরি সিলেক্ট করুন — Vercel/Node সাময়িকভাবে খুঁজে নেবে
4. **Settings** → যোগ করুন:

   ```
   APP_SECRET  =  যেকোনো লম্বা র‍্যান্ডম স্ট্রিং
   PORT        =  3000
   ```

5. **Settings → Networking** → ডিস্ক যোগ করুন, মাউনট পাথ `/data`
6. Deploy শেষ হলে Railway একটি লিংক দেবে

### যেকোনো Node সার্ভারে (VPS/cPanel)

```bash
git clone <আপনার-রিপো> && cd repo
npm install --omit=dev
APP_SECRET="$(openssl rand -hex 32)" DATA_DIR=/var/data/lfj PORT=3000 node server.js
```

`systemd` দিয়ে সার্ভিস হিসেবে চালাতে চাইলে:

```ini
[Unit]
Description=Live Fruit Juice Billing
After=network.target

[Service]
WorkingDirectory=/path/to/repo
ExecStart=/usr/bin/node server.js
Environment=PORT=3000
Environment=DATA_DIR=/var/data/lfj
Environment=APP_SECRET=আপনার-সিক্রেট
Restart=always
User=www-data

[Install]
WantedBy=multi-user.target
```

## নিরাপত্তা

- পাসওয়ার্ড SHA256 হিসেবে জমা; লগইনের সময় সার্ভারে তুলনা হয়
- সেশন টোকেন HMAC-সাইনড, ট্যাম্পার-প্রুফ
- **স্টাফ কখনো পণ্য/স্টাফ/সেটিংস পরিবর্তন করতে পারে না** — সার্ভারে 403
- স্টাফ অন্যের বিল পড়তে পারে না — সার্ভারে 403
- বিলের মোট টাকা **সার্ভারেই** হিসাব হয়, ক্লায়েন্টের সংখ্যা বিশ্বাস করা হয় না
- `seller` সেশন থেকে নেওয়া হয়, ক্লায়েন্ট পাঠাতে পারে না
- শেষ মালিককে মুছে ফেলা বা নিষ্ক্রিয় করা যায় না
- পাসওয়ার্ড হ্যাশ কখনো API রেসপন্সে ফেরত আসে না

**লাইভে নেওয়ার আগে:** `APP_SECRET` অবশ্যই সেট করুন, আর পাসওয়ার্ড বদলান।

## ট্রাবলশুটিং

**সার্ভার পৌঁছানো যায়নি**
→ `npm start` চালু আছে কিনা দেখুন; পোর্টে কিছু চলছে কিনা দেখুন (`PORT=3001 npm start`)

**লগইনে সমস্যা**
→ প্রথমবার ডিফল্ট লগইন `owner` / `owner123`। `data/db.json` মুছে দিলে আবার নতুন করে তৈরি হবে

**পাসওয়ার্ড ভুল হলেও লগইন হচ্ছে না**
→ ফাইলে গেলে এইভাবে হ্যাশ বানাতে পারেন:
  `node -e "console.log(require('crypto').createHash('sha256').update('livefruitjuice_salt_'+(process.argv[1])).digest('hex'))" নতুনপাসওয়ার্ড`

**লাইভ আপডেট আসছে না**
→ কোনো প্রক্সিং সার্ভার SSE ব্লক করতে পারে। অ্যাপ সেক্ষেত্রে ৮ সেকেন্ড পর পুনরায় চেষ্টা করে

**ডেটা চলে গেলে**
→ `data/db.json` ফাইলটাই ব্যাকআপ। নিয়মিত কপি রাখুন, অথবা সেটিংস থেকে "ব্যাকআপ ডাউনলোড" ব্যবহার করুন

**প্রিন্টে পেজের বাকি অংশও আসছে**
→ ব্রাউজারের প্রিন্ট ডায়ালগে "Paper size" 58mm বা "Custom" সিলেক্ট করুন
