# Live Fruit Juice — স্টাফ বিলিং সিস্টেম

দোকান কাউন্টারে ফোন/ট্যাবলেটে ব্যবহারের জন্য একটি সম্পূর্ণ POS বিলিং অ্যাপ।
বাংলা ইন্টারফেস, 58mm রিসিট প্রিন্ট।

**এটি সম্পূর্ণ স্ট্যাটিক ওয়েব অ্যাপ** — কোনো সার্ভার, কোনো ডাটাবেস সার্ভিস,
কোনো ইনস্টল লাগে না। Vercel-এ ফাইল আপলোড করলেই চলবে।

---

## ফিচার

| ফিচার | বিবরণ |
|---|---|
| লগইন | SHA256 (`livefruitjuice_salt_` + পাসওয়ার্ড) — কোনো সার্ভার নয় |
| **স্টাফ রোল** | শুধু নিজের বিল দেখে ও প্রিন্ট করে |
| **ওনার রোল** | সব স্টাফের বিল + স্টাফ ফিল্টার + সম্পূর্ণ নিয়ন্ত্রণ |
| **পণ্য ম্যানেজ** | ওনার অ্যাপ থেকেই পণ্য যোগ/এডিট/ডিলিট ও S/M/L দাম |
| **স্টাফ ম্যানেজ** | ওনার অ্যাপ থেকেই স্টাফ যোগ/এডিট/ডিলিট |
| **সেটিংস** | দোকানের নাম, ঠিকানা, মোবাইল — রিসিটে দেখায় |
| বিলিং | প্রোডাক্ট + সাইজ বাটন, সার্চ, কার্ট, লাইভ টোটাল |
| ফেরত/বাকি | লাইভ হিসাব — ফেরত সবুজ, বাকি লাল |
| রিসিট | 58mm ন্যারো ফরম্যাট, `window.print()`, অটো প্রিন্ট, রিপ্রিন্ট |
| ব্যাকআপ | এক ক্লিকে পুরো ডেটা JSON ফাইলে ডাউনলোড, ফিরিয়েও আনা যায় |
| একাধিক উইন্ডো | একই ডিভাইসে দুটো ট্যাব খোলা থাকলে দুটোই সিঙ্ক থাকে |
| PWA | মোবাইলে "Add to Home Screen" করা যায় |
| শর্টকাট | `F2` সার্চ, `F4` বিল কমপ্লিট |

## দ্রুত শুরু

### লোকালে চালাতে

`index.html` ফাইলটি ব্রাউজারে খুললেই হবে। কোনো ইনস্টল লাগবে না।

### Vercel-এ ডিপ্লয়

1. এই ফোল্ডারটি GitHub-এ পুশ করুন
2. [vercel.com](https://vercel.com) → **Add New** → **Project** → রিপোজিটরি সিলেক্ট করুন
3. **Deploy** চাপুন

ব্যস। কোনো বিল্ড কমান্ড, কোনো Environment Variable লাগবে না —
Vercel নিজে থেকেই static সাইট হিসেবে চালাবে।

> **গুরুত্বপূর্ণ:** প্রতিটি ডিভাইসের ডেটা আলাদা। মালিকের ফোনে যে ডেটা আছে,
> স্টাফের ডিভাইসে সেটা থাকবে না — যদি না ব্যাকআপ ফাইল দিয়ে নিয়ে যান।

## ডেটা কোথায় থাকে

সব ডেটা একটি JSON অবজেক্ট, ব্রাউজারের `localStorage`-এ সেভ থাকে
(`lfj_db_v1` কী)। এতে থাকে:

```json
{
  "settings": { "shop_name": "...", "shop_address": "...", "shop_phone": "..." },
  "employees": [ { "username": "...", "password_hash": "...", "role": "owner" } ],
  "products":  [ { "name": "...", "price_s": 50, "price_m": 80, "price_l": 120 } ],
  "invoices":  [ { "invoice_no": "20260926-001", "total": 310, "seller": "..." } ],
  "invoice_items": [ { "invoice_no": "...", "item": "...", "size": "S", "qty": 2, "price": 50 } ]
}
```

**সুবিধা:** ইন্টারনেট ছাড়াই চলে, সার্ভার লাগে না, খরচ নেই, ইন্টারনেট-স্লো হলেও সমস্যা হয় না।

**অসুবিধা:** ডেটা একটি ডিভাইসেই থাকে। ব্রাউজারের ডেটা মুছে গেলে বা অন্য ফোনে খুললে
আগের ডেটা পাবে না — তাই **নিয়মিত ব্যাকআপ ফাইল নিন** (সেটিংস পেজে উপরে)।

---

## প্রথমবার ব্যবহার

**লগইন:** `owner` / `owner123`

1. **সেটিংস** → দোকানের নাম, ঠিকানা, মোবাইল দিন → সেভ করুন
2. **স্টাফ ম্যানেজ** → স্টাফদের অ্যাকাউন্ট বানান
3. **পণ্য ম্যানেজ** → নিজের পণ্যের দাম দিন (স্যাম্পল পণ্য মুছে দিন)
4. **মালিকের পাসওয়ার্ড বদলান** (স্টাফ ম্যানেজ → owner → এডিট)

### অন্য ডিভাইসে ডেটা নেওয়া

মালিকের ডিভাইসে: সেটিংস → **ব্যাকআপ ডাউনলোড** → একটি JSON ফাইল পাবেন।
অন্য ডিভাইসে: সেটিংস → **ফাইল থেকে ডেটা নিন** → সেই ফাইলটি বেছে নিন।

(লগইন স্ক্রিনেও "ফাইল থেকে ডেটা নিন" লিংক আছে।)

## গুরুত্বপূর্ণ কথা

যেহেতু কোনো সার্ভার নেই, ডেটা ব্রাউজারে থাকে এবং রোল-পারমিশন **অ্যাপের ভেতরেই**
চেক হয় — অর্থাৎ খুব অভিজ্ঞ কেউ ব্রাউজার ডেভটুলস থেকে ডেটা দেখতে পারে।

**তাই:**
- স্টাফকে ভরসার ভিত্তিতে নিয়োগ দিন, সব বিল খোলা থাকে না
- বিলের টাকা ব্যাংকে বেশি জমা রাখবেন না
- মালিকের অ্যাকাউন্ট ও ডিভাইস নিজে কাছে রাখুন
- **নিয়মিত ব্যাকআপ ফাইল নিন**

বিলের হিসাব ১০০% নির্ভরযোগ্য হলে একটি ছোট Node সার্ভার লাগবে (Vercel-এ কাজ করবে না) —
সেটা প্রয়োজন হলে বলবেন, যোগ করে দেব।

## ট্রাবলশুটিং

**লগইন কাজ করছে না**
→ প্রথমবার `owner` / `owner123` চেষ্টা করুন।

**পাসওয়ার্ড ভুল মনে হচ্ছে**
→ এভাবে হ্যাশ বানাতে পারেন (Node ছাড়া):
  ব্রাউজার কনসোলে খুলে লিখুন —
  `crypto.subtle.digest("SHA-256", new TextEncoder().encode("livefruitjuice_salt_"+"নতুনপাসওয়ার্ড")).then(b=>console.log([...new Uint8Array(b)].map(x=>x.toString(16).padStart(2,"0")).join("")))`

**স্টোরেজ পূর্ণ হয়ে গেছে**
→ ব্রাউজারের localStorage সীমা ~5MB। পুরনো বিল ডিউলেট করুন, আগে ব্যাকআপ নিন।

**প্রিন্টে পেজের বাকি অংশও আসছে**
→ ব্রাউজারের প্রিন্ট ডায়ালগে "Paper size" 58mm বা "Custom" সিলেক্ট করুন।

**ফোনে অ্যাপের মতো খুলতে চাই**
→ ব্রাউজারে খুলে মেনু থেকে "Add to Home Screen" চাপুন।

**ভুল ফাইল ইমপোর্ট করলে ডেটা মুছে গেছে**
→ ব্যাকআপ ফাইল থাকলে সেটা আবার ইমপোর্ট করুন। ইমপোর্টের আগে ফাইল যাচাই করা হয়।
